Setting up Flex Query in IBKR

  1. Log in to IBKR Account Management → Reports → Flex Queries
  2. Create a new Activity Flex Query — include the Trades section in XML format
  3. Set date range to "Last N Days" (e.g. 7)
  4. Save the query and note the Query ID
  5. Go to Flex Web Service → Generate Token — note the Token
  6. Add both to your .env file on the RPi

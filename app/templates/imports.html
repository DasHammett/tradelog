Upload Trade File

Supports .tlg (Third-Party TradeLog) and .csv (Activity Statement) files from IBKR.

File is fully validated and checked for duplicates before anything is written to the database.

IBKR Flex Query Sync

Automatically pulls trades from IBKR via the Flex Web Service. Requires FLEX_TOKEN and FLEX_QUERY_ID in your .env file.

Auto-sync runs daily via scheduler.

Recompute ODS & Dashboard

Recomputes all ODS aggregations and daily summaries from the raw STG data. Use this after fixing an import issue or if dashboard numbers look wrong.

How to download your TLG file from IBKR

  1. Log in to IBKR Account Management
  2. Go to Performance & Reports → Statements
  3. On the right side, look for Third Party Downloads
  4. Select TradeLog from the dropdown
  5. Choose your date range and click Run
  6. Download the .tlg file and upload it above

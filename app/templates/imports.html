Recomputes all ODS aggregations, RT trades, and daily summaries from raw STG data. Use this if dashboard numbers look wrong after an import.

How to export a Flex XML file from IBKR

  1. Log in to IBKR Account Management
  2. Go to Performance & Reports → Flex Queries
  3. Find your Commissions query and click Run
  4. Set your desired date range (e.g. for a historical backfill)
  5. Select XML format and click Run
  6. Download the .xml file and upload it above
